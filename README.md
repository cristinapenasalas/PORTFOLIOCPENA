# Cristina Peña — Portfolio

Portafolio personal de Cristina Peña: comunicación digital y desarrollo web.

Construido con React + TypeScript + Vite. Incluye modo claro/oscuro y selector de idioma (ES/EN).

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Estructura

- `src/context` — tema (claro/oscuro) e idioma (ES/EN), persistidos en `localStorage`.
- `src/data/content.ts` — textos y contenido de las secciones, en ambos idiomas.
- `src/components` — Header, Footer, tarjetas de proyecto, layout.
- `src/pages` — Home (completa) y páginas placeholder para Sobre mí, Proyectos, Servicios y Contacto, pendientes de construir.
